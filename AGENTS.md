# Stock Agent coding instructions

This is a local Python/Streamlit stock-analysis app.

Rules:
- Do not change trading/scoring logic unless explicitly asked.
- Prefer small, focused commits.
- Keep existing function names unless asked.
- Do not hardcode portfolio/watchlist data in .py files.
- Use JSON config/data files under data/.
- Preserve TEST/PROD separation via STOCK_AGENT_ENV.
- After changes, run import checks if possible.
- Do not add cloud/backend dependencies without approval.
